# «Чёрный сигнал» — GitHub Pages

Статический сайт сюжетного события в SCP: Secret Laboratory на сервере Legacy.

## Структура

- `index.html` — главная страница и обратный отсчёт;
- `factions.html` — публичные статьи о группировках;
- `briefing.html` — формат и этапы события;
- `info.html` — дата, сервер и регистрация;
- `signals.html` — архив сюжетных передач;
- `wip.html` — временная заглушка;
- `404.html` — страница для неверных адресов;
- `styles.css` — оформление;
- `script.js` — мобильное меню и таймер;
- `assets/` — изображения.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.

Сайт будет доступен по адресу:

`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

Файл `.nojekyll` отключает ненужную обработку Jekyll. Все ссылки относительные, поэтому сайт работает как в корне домена, так и внутри репозитория.

## Изменение даты

В `index.html` найдите:

`data-countdown="2026-10-09T21:00:00Z"`

Это 10 октября 2026 года, 00:00 по московскому времени.
